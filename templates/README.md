# Illustrator templates

Place approved Adobe Illustrator `.ai` production templates in this directory.

Designers must follow [`docs/illustrator-template-standard.md`](../docs/illustrator-template-standard.md).

Expected example filename: `alternative-syrup.ai`

Automation targets named objects such as `PRODUCT_NAME`, `NET_WEIGHT`, `UPC`, and `QR_CODE`.
Locked layers such as `BRAND_MARK`, `DIELINE`, and `PRODUCTION` are never modified by the bridge.
